# Updating AliasVault

To update your self-hosted AliasVault server, follow the update guide for the installation method you used:

- [Install Script](./script/update/index.md): you installed AliasVault with `install.sh`.
- [Docker Compose](./docker-compose/update/index.md): you run the all-in-one `ghcr.io/aliasvault/aliasvault` container.
