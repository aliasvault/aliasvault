# Self-host Install

AliasVault can be self-hosted in two ways. Both use and require Docker, but they differ in how TLS, updates and the surrounding setup are handled. Pick the one that fits your setup.

:::tip You can switch later
Both methods use the same bind-mount directories (`/database`, `/certificates`, `/logs`, `/secrets`), so you can stop one setup and install the other on top of the same data.
:::

## System requirements

- 64-bit Linux (Ubuntu or RHEL-based recommended)
- 1 vCPU, 1 GB RAM and 5 GB free disk space (16 GB total disk recommended)
- Docker CE 20.10 or newer and Docker Compose 2.0 or newer
- Ports 80 and 443 available, and optionally ports 25 and 587 to receive email on your own domains
